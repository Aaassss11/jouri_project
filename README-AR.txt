تحديث واجهة مفروشات جوري

الملفات: index.html وstyles.css وmanifest.webmanifest.
قبل الاستبدال احفظ نسخة احتياطية. ارفع الملفات الثلاثة إلى جذر المستودع GitHub مكان الملفات المناظرة، ثم انتظر نشر Cloudflare Pages.
أضيف شريط تنقل سفلي للهاتف وخطوط أيقونات Font Awesome عبر CDN، مع رفع تباين الكتابة داخل القائمة الجانبية.
ملاحظة: Font Awesome يحتاج اتصال إنترنت لتحميل الأيقونات من CDN. هذا تعديل واجهة، لا يغير app.js أو قاعدة البيانات. اختبر الموقع بعد النشر.
