# نظام مفروشات جوري المحاسبي مع Modon Express

تطبيق محاسبي RTL من الصفر يربط دورة البيع مع المخزون والديون والقاصة وحسابات الموظفين وطلبات Modon.

## التشغيل

```powershell
node server.js
```

ثم افتح:

```text
http://127.0.0.1:8080
```

## ربط Modon الحقيقي

انسخ ملف المثال:

```powershell
Copy-Item modon-accounts.example.json modon-accounts.json
```

ثم ضع بيانات حسابات الموظفين الحقيقية داخل `modon-accounts.json`.

الخادم المحلي `server.js` هو الذي يتصل بـ Modon:

- `GET /api/modon/cities`
- `GET /api/modon/regions?city_id=...`
- `GET /api/modon/package-sizes`
- `POST /api/modon/create-order`

بهذا لا تعتمد الواجهة على قوائم تجريبية للمدن والمناطق، بل تجلبها من Modon مباشرة.

## الميزات الحالية

- إنشاء فاتورة بيع بثلاث طرق:
  - بيع نقد مباشر يدخل القاصة.
  - بيع دين على الزبون يدخل ذمم الزبائن.
  - بيع تقسيط مع دفعة مقدمة وجدول أقساط.
- فاتورة البيع احترافية ومتعددة البنود:
  - أكثر من منتج في نفس الفاتورة.
  - خصم لكل بند.
  - خصم عام للفاتورة.
  - مدفوع الآن ومتبقي.
  - جدول أقساط عند اختيار التقسيط.
- طلبات Modon أصبحت في قسم مستقل عن فاتورة البيع العادية:
  - نموذج مستقل لإنشاء طلب Modon.
  - الطلب يسجل رقمًا داخليًا يبدأ بـ `MODON`.
  - الطلب يدخل مستحقات شركة التوصيل ولا يدخل القاصة قبل القبض.
- المحافظات والمناطق وأحجام الطرود في نموذج Modon تُجلب من API مدن عبر الخادم المحلي.
- حسابات موظفين متعددة، وكل موظف له حساب Modon مستقل.
- صلاحيات احترافية للموظفين:
  - قوالب جاهزة: مبيعات، محاسب، مسؤول مخزون، مدير.
  - صلاحيات تفصيلية مثل إنشاء الفواتير، تعديل الأسعار، متابعة Modon، إدارة المخزون، الديون، القاصة، التقارير، وإدارة الموظفين.
- فلتر إداري أعلى الصفحة:
  - كل الحسابات.
  - حساب موظف محدد.
- تقارير Modon لكل موظف منفصلًا، وتقارير مجمعة لكل الحسابات.
- متابعة عدد الطلبات اليومية لكل حساب، الحالات، المسلمة، المشاكل، الراجع، صافي التاجر، والمستحقات.
- شاشة مستقلة باسم `المخزون الافتتاحي` لتثبيت أرصدة البداية بدون اعتبارها فاتورة شراء.
- فواتير شراء من الموردين:
  - رأس فاتورة: مورد، رقم فاتورة المورد، التاريخ، طريقة الدفع، ملاحظات.
  - بنود متعددة: المنتج، الكمية، كلفة الوحدة، سعر البيع.
  - الفاتورة النقدية تخصم من القاصة.
  - الفاتورة الآجلة تسجل ذمة على المورد.
  - كل بند يزيد المخزون آليًا.
  - يمكن إضافة عدد غير محدود من بنود الشراء بزر إضافة بند.
- موردون مرتبطون بالمنتجات وإدخالات المخزون.
- منع البيع إذا الكمية غير كافية.
- رجوع طلب Modon يعيد الكمية إلى المخزون.
- ديون زبائن مع تسجيل قبض جزئي أو كامل.
- ديون شخصية تخصم مباشرة من القاصة.
- فواتير Modon للطلبات المسلمة غير المفوترة، ثم تأكيد القبض لإدخال صافي المبلغ إلى القاصة.
- تصدير تقرير CSV وطباعة التقرير.
- طباعة احترافية للفواتير والسندات:
  - فاتورة البيع.
  - وصل طلب Modon.
  - فاتورة الشراء.
  - سند/حركة المورد.
  - قالب طباعة موحد بترويسة مفروشات جوري وجداول ومجاميع.
